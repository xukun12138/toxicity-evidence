# Author portraits

These portraits identify the authors of the survey on its About page. They originate from the authors' personal websites or institutional profiles. The original URLs, profile sources, check date, and image hashes are recorded in [authors.json](../data/authors.json).

The WebP files are proportionally resized copies (at most 480 by 580 pixels). No facial or background alterations have been made. Larger original files are not included in the repository.

Copyright remains with the respective photographers and other rights holders. The repository's MIT code license does not apply to these portraits. Inclusion here does not grant permission for unrelated reuse. Please use the linked primary profile or repository issue tracker for a correction or removal request.
